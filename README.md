# site

Maschinell erzeugt. Dieser Branch enthaelt die gebaute App in `site/`,
gepusht von der CI nach einem gruenen Lauf auf `main`. Die Betreffzeile
des Commits ist der `main`-Commit, aus dem der Build stammt.

Hier von Hand etwas zu aendern ist sinnlos: der naechste gruene Lauf
ueberschreibt den Branch.
